# shared/fixtures (Saksham's routing + alerts set)

These are generated by `make -C routing fixtures` from the **real writers**, run on the synthetic dev world
(`make -C routing demo-local` first). All values are synthetic. Each file validates against `jt_shared.models`
(`shared/py/tests/test_fixtures.py`).

| File | Schema | What it shows |
|---|---|---|
| `road_segment_status.json` | `[RoadSegmentStatus]` | 15 red + 10 amber edges at `T_hero` |
| `evacuation_plans.json` | `{valid_at: [EvacuationPlan]}` | 5 steps (`T_hero` −6 h … +6 h) × hero, backup hero and one more colony. Colonies drop out once they are wet |
| `plans_unreachable.json` | `[UnreachableEntry]` | `already_wet` colonies (the UI shows them as "boat / NDRF needed") |
| `plans_candidates.json` | candidates rows | the hero's K=3 shelters, best/alt routes, allocations |
| `trap_summary.json` | `TrapSummary` | trap counter over the fixture steps |
| `hero.json` | — | `T_hero` + backup hero (SHARED §11.8-1) |
| `edge_cutoffs_sample.json` | `{edge_id: level}` | sample of `static/osm/edge_cutoffs.json` (what-if slider input) |
| `shelters.json` | `[Shelter]` | seeds with `free_beds` |
| `dispatch_card.json` | `DispatchCard` | URGENT for the hero, template path |
| `dispatch_card_fallback.json` | `DispatchCard` | an LLM draft where `message_en` failed and fell back to the template (`fallback_fields`) |
| `dispatch_card_shelter_in_place.json` | `DispatchCard` | SHELTER_IN_PLACE for an already-wet colony |
| `dispatch_cache_sample.json` | `{key, card}` | one `scenarios/<id>/dispatch_cache/<t>/<colony>.json` entry |
| `report_post_response.json` | `ReportPostResponse` | `POST /reports` with a presigned upload (placeholder signature) |
