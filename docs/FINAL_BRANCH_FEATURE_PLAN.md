## 3. Must (no video without these)

### M1. Frontend MVP: Command view · ~5 h
- **What:** React + Vite + MapLibre on the **static data ladder** (SHARED §11.4): read `scenarios/<id>/{manifest,plans,roads}` from the
  bucket or CloudFront, fall back to `shared/fixtures/`. A timeline scrubber over `manifest.valid_at`, the flood polygon
  layer, roads coloured red/amber, colony pins coloured by time-to-water, and the plan list sorted by priority.
- **Done when:** scrubbing to `manifest.default_at` shows the hero colony on top with its primary/backup route and the
  avoid road highlighted.
- **Data you can use today:** `shared/fixtures/*.json` (generated by the real writers), `routing/hero.json`, `trap_summary.json`.

### M2. Dispatch card in the UI · ~2 h
- **What:** select a colony, click **Draft**, see the Hindi/English/SMS card with the six validator chips, the fallback
  banner when `fallback_used`, and the audio player. Then **Approve** shows `sent`.
- **Auth:** the draft/approve routes use AWS_IAM. Fastest option: a **Cognito identity pool** with an unauthenticated role
  limited to `execute-api:Invoke` on those routes, and sign requests with `aws4fetch`. Fallback for the recording: read the
  pre-drafted card from `dispatch_cache/<t>/<colony>.json` (already published).

### M3. Hosting · ~1 h
- **What:** `npm run build`, then the `dist/` upload. Use Amplify zip deploy (SHARED §11.8-12) or S3 `web/` behind CloudFront. Add a
  CloudFront distribution with OAC for `static/`, `scenarios/` and `tiles/` (403/404 = "absent", §11.8-9).
- **Done when:** one public URL loads the app and the data, and it works with the API turned off.

### M4. Golden test on the deployed stack · ~1 h
- **What:** `make golden ENV=demo` checks SHARED §9.2 at `manifest.default_at`: the forecast is in its band, the flood touches
  the hero, a plan exists with `max_depth_m ≤ 0.30`, there are 0 red primaries, and the dispatch is valid (≤ 160 chars, only 1077/112).
- **Why:** it is the Sun 09:00 checkpoint, and the output is a slide.

### M5. Real data where it is cheap · ~2–3 h (cut to "labelled synthetic" if late)
- **What:** at minimum, the **real July 2023 Delhi Railway Bridge curve** (digitised anchors from SHARED §1 plus press
  readings, `source="digitized"`) feeding `ml` → routing → alerts, and the real colony/shelter names (the populations stay synthetic,
  and are labelled so). The DTM and OSM graph are the bigger lifts; if they don't land, keep the dev world and **say so on screen**.
- **Rule:** never present synthetic numbers as real. Every number on screen shows a source chip.
